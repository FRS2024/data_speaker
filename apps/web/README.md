# Web Application Client (`apps/web`)

This directory houses the Next.js 14 split-pane user interface for the Conversational Data Analysis Platform.

### Planned Stack (Phase 4):
* **Framework:** Next.js 14 (App Router, TypeScript)
* **Styling:** Tailwind CSS, Shadcn UI
* **Visualization:** `react-plotly.js` (Plotly.js WebGL/Canvas rendering)
* **Code Editor:** Monaco Editor (`@monaco-editor/react`)
* **Communication:** Server-Sent Events (SSE) streaming consumer
