# Web Application Client (`apps/web`)

This directory houses the high-performance TanStack Router + Vite Single Page Application (SPA) for the Conversational Data Analysis Platform.

### Technical Stack:
* **Framework & Tooling:** Vite, React 18, TypeScript
* **Routing & State:** TanStack Router (`@tanstack/react-router`), TanStack Query (`@tanstack/react-query`)
* **Tables & Virtualization:** TanStack Table (`@tanstack/react-table`), TanStack Virtual (`@tanstack/react-virtual`)
* **Styling:** Tailwind CSS, Material Symbols
* **Visualization:** `react-plotly.js` (Plotly.js WebGL/Canvas rendering)
* **Code Editor:** Monaco Editor (`@monaco-editor/react`)
* **Communication:** Server-Sent Events (SSE) streaming consumer (`useChatStream`)
